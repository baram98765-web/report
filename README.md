# C언어 모래시계 패턴 출력 프로그램
```c
#include <stdio.h>

int main() {
    int n;
    int i, j;

    scanf_s("%d", &n);

    if (n < 3 || n % 2 == 0) {
        return 0;
    }

    for (i = 0; i <= n / 2; i++) {
        for (j = 0; j < i; j++) {
            printf(" ");
        }

        for (j = 0; j < n - 2 * i; j++) {
            printf("*");
        }

        printf("\n");
    }

    for (i = n / 2 - 1; i >= 0; i--) {
        for (j = 0; j < i; j++) {
            printf(" ");
        }

        for (j = 0; j < n - 2 * i; j++) {
            printf("*");
        }

        printf("\n");
    }

    return 0;
}
```

# 소스코드 상세 설명

### 1. 입력 검증 및 예외 처리
```c
if (n < 3 || n % 2 == 0) {
    return 0;
}
```
* `n < 3` 조건으로 3 미만의 정수를 차단하고, `n % 2 == 0` 조건으로 짝수를 걸러냅니다.
* 조건에 맞지 않는 입력값이 들어오면 비정상 출력을 방지하고 즉시 프로그램을 종료합니다.

### 2. 상단부 출력 (역삼각형 구간)
```c
for (i = 0; i <= n / 2; i++) {
    for (j = 0; j < i; j++) {
        printf(" ");
    }
    for (j = 0; j < n - 2 * i; j++) {
        printf("*");
    }
    printf("\n");
}
```
* **줄 반복 (`i`)**: `0`부터 `n / 2`까지 증가하며 상단부와 중앙까지의 줄을 제어합니다.
* **공백 제어**: `i`번째 줄마다 `i`개의 공백을 출력하여 정렬 위치를 맞춥니다.
* **별 제어**: `n - 2 * i` 수식을 통해 매 줄마다 별의 개수를 2개씩 줄여나갑니다. ($N \rightarrow N-2 \rightarrow \dots \rightarrow 1$)

### 3. 하단부 출력 (정삼각형 구간)
```c
for (i = n / 2 - 1; i >= 0; i--) {
    for (j = 0; j < i; j++) {
        printf(" ");
    }
    for (j = 0; j < n - 2 * i; j++) {
        printf("*");
    }
    printf("\n");
}
```
* **대칭 구조 활용**: 인덱스 `i`를 `n / 2 - 1`부터 `0`까지 1씩 감소(`i--`)시키며 거꾸로 반복합니다.
* 상단부와 동일한 공백 수식(`i`개)과 별 수식(`n - 2 * i`개)을 그대로 재활용하여 모래시계의 상하 대칭을 효율적으로 구현했습니다.
